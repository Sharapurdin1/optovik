# Подготовка «Оптовика» к продакшену

Глобальная задача: перевезти проект с Vercel + Turso на Timeweb Cloud, привязать
домен с reg.ru, сделать полноценную админку каталога со складом и фото в S3,
а Telegram оставить только для уведомлений о новых заказах.

Статусы: `[ ]` не начато · `[~]` в работе · `[x]` готово

---

## Архитектурные решения (зафиксировать до начала работ)

| Вопрос | Решение | Почему |
|---|---|---|
| Хостинг | **Timeweb Cloud VPS + Docker Compose**; перед приложением Caddy (сам выпускает и продлевает SSL) | Дешевле, полный контроль. Взамен сами отвечаем за обновления и безопасность сервера |
| База данных | **Managed PostgreSQL в Timeweb** вместо Turso | 152-ФЗ: персональные данные (имя, телефон, адрес) должны храниться в РФ; нужны транзакции для списания остатков; бэкапы из коробки |
| Файлы (фото) | **S3 Timeweb Cloud** (тот же провайдер/регион) | Дёшево, быстро, S3-совместимый API |
| Каталог | Переезжает **из Google-таблицы в БД**, правится в админке | Нужны остатки, фото, мгновенное обновление |
| Схема БД | Миграции через `drizzle-kit generate` + `migrate` (не `push`) | Предсказуемые изменения схемы на проде |
| Код и деплой | GitHub (приватный репозиторий) → GitHub Actions собирает Docker-образ → GHCR → по SSH на VPS `docker compose pull && up -d` | Сейчас у репозитория нет remote; на слабом VPS образ не собираем |
